## Why Cursor is Great for Studying

Cursor is exceptionally well-suited for building knowledge bases because:

- **Local content awareness** - It reads and understands your entire project, not just isolated prompts
- **Contextual accuracy** - No hallucinations because it references actual files and content
- **Code + documentation** - Perfect for technical subjects that combine math, code, and explanations
- **Project structure understanding** - Maintains consistency across hundreds of files
- **Procedural memory** - Can follow guides and rules you've established

This combination makes Cursor ideal for students and researchers who need accurate, context-aware assistance with their work.

## How I'm Using Cursor

I've built a mathematics knowledge base with 214+ problems, exam archives (2014-2025), reference materials, and automated scripts. My workflow:

- Extract content from PDFs (time-consuming—see request #5)
- Organize problems by topic with AI assistance
- Generate indexes and cross-references
- Create explained solutions with step-by-step reasoning
- Maintain project rules in `.cursor/rules/` and procedures in `.cursor/guides/`

**Key discovery:** Using `.cursor/rules/` for project conventions and `.cursor/guides/` for procedures helps maintain consistency across hundreds of files and ensures the AI follows my standards automatically.

## Feature Requests

### 1. Mobile Access (Most Critical)
All my data is local and Cursor isn't available on mobile. I need:
- Web-based Cursor or mobile app
- Remote control to access PC Cursor from phone

### 2. Enhanced Markdown
- Preview mode by default for `.md` files
- Font size, font family, and theme customization
- Better LaTeX rendering
- Obsidian-style WYSIWYG editing

### 3. LaTeX Rendering in Chat
When AI explains math in LaTeX, it's unreadable. I often ask it to write to files just to read them. Please render LaTeX equations in chat responses.

### 4. Built-in Export Tools
- Export to PDF with LaTeX rendering
- Export to Word (.docx)
- Batch export capabilities

### 5. Improved PDF Extraction
My process (extract pages as images, then AI reads each one) is extremely time-consuming. Need direct PDF text extraction with batch processing.

### 6. Auto-Load Project Rules
Auto-load `.cursor/rules/` and `.cursor/guides/` at session start instead of manually telling Cursor each time.

### 7. Knowledge Base Template
A default guide/template for students building knowledge bases.
