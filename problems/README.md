# Problems Collection

This directory contains 214 mathematical problems covering vector calculus, complex analysis, and related topics.

## Overview

- **Total Problems:** 214
- **Format:** Each problem is in its own markdown file
- **Naming Convention:** `problem_XXX.md` where XXX is zero-padded (001-214)
- **Images:** Problem images are stored in the `images/` subdirectory
